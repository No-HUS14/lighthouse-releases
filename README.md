# LIGHTHOUSE

絵コンテ / ビデオコンテ制作ツール（Windows）

## ダウンロード

**[最新版をダウンロード](https://github.com/No-HUS14/lighthouse-releases/releases/latest)**

1. 上のリンクを開き、「Assets」にある `LIGHTHOUSE-Setup-<バージョン>.exe` をダウンロードします
2. ダウンロードしたファイルを実行して、画面の案内に従ってインストールします
   （初回は Windows SmartScreen が表示されることがあります。「詳細情報」→「実行」を選んでください）

インストール後は、新しいバージョンが出ると起動時にお知らせします。アプリの中から更新できます。

過去のバージョンと変更内容は [Releases](https://github.com/No-HUS14/lighthouse-releases/releases) にあります。
